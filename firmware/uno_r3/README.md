# Uno R3 固件归档

主程序位于：

```text
medicine_box_r3/medicine_box_r3.ino
```

程序负责RTC时钟、OLED显示、按键校时、早中晚三次服药提醒、LED与GD5800音频播放，
并接收树莓派发送的四位数字串口指令。

## 依赖库

- U8g2
- RTClib
- GD5800_Serial

## 串口约定

- `9600 8N1`，无流控；
- 下行格式为四位ASCII数字加换行，例如`0005\n`；
- 有效指令入队后回复`ACK\n`，未知指令回复`ERR\n`；
- 树莓派端等待ACK最多`2.0秒`，不自动重发，避免重复播放；
- 正式联调保持固件中的`DEBUG_SERIAL`为`0`。

完整编号与接线说明参见仓库根目录的`R3串口通信对接说明.md`。

# 流感预警与 API 基础源码

本目录只保留实现最终流感功能所需的运行代码，不含人脸识别、红外测温、测试代码、
历史补录工具、数据库、PDF、缓存、虚拟环境或密钥。

## 目录

- `workers/flu_updater/`：树莓派从中国疾控中心官网获取、解析并上传最新周报。
- `raspberry_pi/weekly_alert.py`：树莓派读取云端风险并向 Uno 发送音频编号。
- `src/flu_runtime/flu_api.py`：云端 API 客户端及断网缓存。
- `src/flu_runtime/uno.py`：`0009/0010/0011` 串口发送与 ACK 处理。
- `cloud/flu_web/`：云端数据库、API、网页、AI 月报和微信推送。
- `deploy/systemd/`：每周一 10:00 自动运行的树莓派服务与定时器。

## 数据流程

```text
疾控中心官网 PDF
  -> 树莓派下载与解析
  -> Bearer Token 上传云端
  -> 云端风险分级、网页展示、AI 月报、微信通知
  -> 树莓派读取最新风险
  -> Uno 播放高/中/低风险音频 0009/0010/0011
```

周风险采用确定性规则，只表示公共卫生信息风险，不是个人诊断。DeepSeek 只负责
月度文字归纳。所有 API Key、公众号凭据和上传令牌均应在部署环境中配置，不得写入
源码。
